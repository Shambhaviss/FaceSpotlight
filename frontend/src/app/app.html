TECHNICAL OVERVIEW

How the Model Works

FaceSpotlight follows a computer vision and machine learning pipeline to classify celebrity face images.

01 ◎

Face Detection

OpenCV Haar Cascade detects face regions and selects the largest detected region.

02 ▣

Preprocessing

The selected face is converted to grayscale and resized to 100 × 100 pixels.

03 ⌗

HOG Extraction

Histogram of Oriented Gradients extracts local edge and gradient information.

04 ✦

SVM Prediction

An RBF-kernel Support Vector Machine predicts one of nine known classes.

PROJECT INFORMATION

About FaceSpotlight

Learn about the purpose and architecture of this project.

Project Overview

FaceSpotlight is a closed-set celebrity face classification system. It predicts one of nine celebrity categories represented in its training dataset. It is not a general-purpose identity verification system.

Application Architecture

Angular provides the user interface, FastAPI exposes the prediction endpoint, and the trained preprocessing and SVM pipeline performs image classification.

Python OpenCV HOG Scikit-learn RBF SVM FastAPI Angular TypeScript
